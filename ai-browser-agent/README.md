# GuideDot AI Browser Agent

A Manifest V3 Chrome extension that reads a compact, privacy-preserving DOM summary, asks the local SchemeSathi backend for a safe next step, then guides the user with a small visual avatar. It never moves the real mouse or performs clicks, typing, submissions, authentication, CAPTCHA, OTP, or payment actions.

## Run locally

1. Keep the SchemeSathi app running on `http://localhost:3000` and set `OPENAI_API_KEY` in its root `.env.local` file. The extension uses a safe rule-based fallback when it is absent. Its backend URL is configured in `.env.local` (copy `.env.example` if needed).
2. In this folder, install packages with `pnpm install` and run `pnpm build`.
3. In Chrome, open `chrome://extensions`, enable **Developer mode**, choose **Load unpacked**, then select this folder's `dist` directory.

The overlay uses `@floating-ui/dom` to position the white active avatar beside the live target. The inactive avatar is black; the active avatar is white. Target coordinates are calculated in the content script at runtime after scrolling, never generated by the model.

Never put AI keys, JWT secrets, or passwords in the extension `.env.local`: `VITE_` values are compiled into the extension. Keep secrets only in the SchemeSathi server's root `.env.local`.

The extension planner model is configured server-side with `BROWSER_AGENT_MODEL=gpt-5.6-luna` in the SchemeSathi root `.env.local`.

For Kannada voice use, select **ಕನ್ನಡ** in the popup before activating the agent. This sets Kannada speech recognition (`kn-IN`), requests Kannada-script guidance from the AI planner, and selects a Kannada browser voice when one is installed.
